# Student Management System

A web-based Student Management System developed using **Java, JSP, JDBC, and MySQL**. This project provides a simple and efficient way to manage student records through a web application.

## 📌 About the Project

The Student Management System is a Java-based web application that allows users to manage student information easily.

The application performs basic **CRUD operations** such as adding, viewing, updating, and deleting student records.

This project was developed to understand and implement Java web development concepts, JSP, JDBC, MySQL database connectivity, and Apache Tomcat.

## 🚀 Features

* Add new student records
* View student records
* Update existing student information
* Delete student records
* MySQL database integration
* JDBC database connectivity
* JSP-based web interface
* Simple and user-friendly interface

## 🗄️ Database

The project uses **MySQL** to store and manage student information.

The application connects to the MySQL database using **JDBC**.

### Database Configuration

Before running the project:

1. Install MySQL.
2. Create the required database.
3. Create the student table.
4. Configure the database connection details in the project.
5. Make sure the MySQL server is running.

> Do not upload database passwords or other sensitive credentials to GitHub.

## ⚙️ How to Run the Project

### Prerequisites

Make sure the following are installed:

* Java JDK
* Eclipse IDE
* Apache Tomcat
* MySQL
* Git

### Steps

1. Clone the repository:

```bash
git clone https://github.com/Vinay-7974/Student-Management-System.git
```

2. Open the project in Eclipse.

3. Configure Apache Tomcat Server.

4. Configure the MySQL database.

5. Update the database connection details according to your MySQL setup.

6. Start the MySQL server.

7. Run the project using Apache Tomcat.

8. Open the application in your browser.
